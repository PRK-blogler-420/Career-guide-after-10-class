## 📌 Project Overview

**CareerPath Karnataka** brings multiple education and career pathways
into one simple, mobile-friendly interface.

``` text
Class 10 / SSLC
      │
      ├── PUC
      │    ├── Science → PCMB / PCMC / PCMS
      │    ├── Commerce → CEBA / SEBA / EBAC
      │    └── Arts → HEBA / HEPS / HESP
      │
      ├── Diploma
      ├── ITI
      └── Defence & Government
```

The navigation follows:

**Path → Combination → Degree → Course → Detailed Information**

# 📖 Course Detail System

Clicking a course opens a dedicated information panel.

The panel can explain:

-   Course overview
-   Typical duration
-   Eligibility
-   Course category
-   Availability level
-   Skills required
-   Future scope
-   Karnataka college/institute information
-   What to check before admission
-   Research/reference information

For example:

``` text
Aeronautical Engineering
        ↓
Course Overview
        ↓
Duration
        ↓
Eligibility
        ↓
Skills Required
        ↓
Future Scope
        ↓
Karnataka Availability
```

This structure is also used for other degree, diploma, ITI and career
pathways.

# 🤖 AI Career Assistant

CareerPath includes a floating **AI Career Guide**.

Example questions:

``` text
What can I do after PCMB?

Show all BTech courses.

Tell me about Aeronautical Engineering.

What skills are required for CSE?

Tell me about ITI.

What diploma courses are available?

Tell me about Indian Army careers.

What is the future scope of BCA?

How can I explore engineering colleges in Karnataka?

Who is the owner of this website?
```

The current version uses a client-side career knowledge base and
response logic, so the built-in assistant does not require an external
API key.

# 🔍 Research & Verification

CareerPath Karnataka is a guidance project rather than an official
admission authority.

Students should verify current:

-   Eligibility
-   Fees
-   Seat availability
-   Course approval
-   Entrance examinations
-   Admission dates
-   College availability
-   Government recruitment requirements

Reference portals:

-   [VTU](https://vtu.ac.in/)
-   [Karnataka Department of Technical
    Education](https://dtek.karnataka.gov.in/)
-   [Directorate General of Training](https://dgt.gov.in/)
-   [KEA](https://cetonline.karnataka.gov.in/kea/)
-   [NCERT My Career Advisor](https://mycareeradvisor.ncert.gov.in/)

------------------------------------------------------------------------

# ⚠️ Disclaimer

CareerPath Karnataka is an educational guidance project.

The website is intended to help students **explore possibilities**. It
does not replace official admission notifications, university
regulations, government recruitment notifications or professional
counselling.

Course names, eligibility, fees, entrance examinations, seat matrices
and college availability may change.

**Always verify important information with the relevant official
authority before making an admission or career decision.**
